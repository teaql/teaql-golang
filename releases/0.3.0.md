# TeaQL Go 0.3.0

Tracking: [release issue 43](https://github.com/teaql/teaql-golang/issues/43).

This release publishes the merged request intent and Trace Chain implementation,
including independent mutation graphs, shared references, relation aggregates,
facet tracing, numeric operations and safe SQL diagnostics.

Regenerate applications when upgrading from 0.2.x: request and lineage
contracts have changed. Logging remains enabled by default, with sensitive
parameters masked and the existing disable controls preserved.

Release gates cover native tests, every retained example, an isolated generated
consumer of the immutable internal v0.3.0 module, and public Go module delivery.
External-provider skips are recorded separately; they are not passing tests.
