# Go 0.3.1

Tracking: [Go #48](https://github.com/teaql/teaql-golang/issues/48) and
[conformance #109](https://github.com/teaql/teaql-conformance/issues/109).

The optional `telemetry/standard` module registers once at application assembly
and uses the three trusted telemetry environment variables. It requires Go 1.25
or later; the core module retains its Go 1.18 compatibility floor. Both modules
use matching versions, with tags `v0.3.1` and `telemetry/standard/v0.3.1`.

Full safe traces, metrics and logs retain expanded masked SQL and carried physical
identity. Bounded SDK work, finite lifecycle and acknowledgement/loss accounting
preserve customer globals, business results and independent audit.

Regenerate libraries for request-tree/search metadata and ordinary list pagination;
there is no separate page terminal. Source/internal qualification is retained in
the conformance `2026-10-13-standard-telemetry-onboarding` report. Final internal
artifacts, signed tags and public consumption remain distinct release gates.
